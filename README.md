# iNotes
It is a starting project to learn about fast api


This project help users to create notes which include multiple options
1. Users can add title to their note
2. Users can add Description on their note
3. User can also marke their note done or undone whenever they waht to

# Tech Stack
I have used FastAPI to create a basic backend for this app 

# Note
This app only made up with backend and has no UI so this app can only be managed by making api requests
